# Graph-Based Skill Matching and Candidate-Job Recommendation - code

Everything in the thesis experiments is generated by this code. No numbers are typed in by hand.

## Files
| File | What it does |
|---|---|
| `gm.py` | Core library: skill taxonomy (85 skills, 6 generic, 23 roles, 8 domains), synthetic benchmark generator with known ground truth, heterogeneous graph + skill co-occurrence graph, baselines B1-B4, graph methods G-B..G-E, Hungarian assignment (G-A), metrics, explanation generator |
| `experiments.py` | Runs all experiments -> `results/*.csv`, `results/summary.json` (about 1 min) |
| `explain_example.py` | Finds a case where keyword matching fails and the graph succeeds; writes `results/explanation_example.json` |
| `make_figures.py` | Draws every figure into `figures/` (300 dpi PNG) |
| `results_table.py` | Prints the result tables as Markdown (`results/results_tables.md`) |
| `demo.py` | 2-second live demo for the viva |

## Run
```
pip install numpy pandas networkx scikit-learn scipy matplotlib tabulate
python experiments.py
python explain_example.py
python make_figures.py
python results_table.py > results/results_tables.md
python demo.py
```
Everything is seeded (seeds 0-4), so results are reproducible.

## Method summary
* B1 Jaccard on raw strings, B2 TF-IDF cosine on raw strings, B3 Jaccard after alias normalisation, B4 LSA (16-d SVD).
* G-B: cosine after expanding each profile by the skill-graph adjacency (W + I).
* G-C: cosine of skill vectors weighted by log(1 + 1/DC(s)), DC = degree centrality in the recruitment graph.
* G-D: cosine of profile distributions over Louvain communities.
* G-E: personalised PageRank (alpha = 0.85, 30 iterations) on the heterogeneous graph, restart at the job node.
* G-A: Hungarian assignment (`scipy.optimize.linear_sum_assignment`) vs greedy, 300 jobs from a pool of 360 candidates.

## Honest limitations
* Data is synthetic. Relevance = share of a job's required skills in the candidate's hidden skill set (2 if >= 80%, 1 if >= 60%).
  The generator and the ground truth were written by the same author, so absolute scores are optimistic. Only the relative comparison is meaningful.
* NDCG/precision are averaged over jobs (or candidates) that have at least one relevant item.
* The 1-point gain of G-C over B3 is consistent over 5 seeds (differences 0.009-0.015) but no formal significance test has been run yet.
